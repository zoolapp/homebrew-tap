# ZOOL Homebrew tap

```bash
brew install --cask zoolapp/tap/aime
```

| Cask | App |
|---|---|
| `aime` | [AIME](https://aime.zool.app/) — AI-enhanced Chinese input method for macOS 26+ (installs to `/Library/Input Methods`) |

Upgrade with `brew upgrade --cask aime`. Uninstall with `brew uninstall --cask aime`; add `--zap` to also remove settings and user dictionaries.

To bump a release: `bash scripts/update-cask.sh <version>`.
